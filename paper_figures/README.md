# Section 5.3 figures — reproduction bundle

Self-contained reproduction of the three Section 5.3 figures of the FDFL paper
(the manuscript uses a subset of them). No project install required.

## Contents

```
plot_sec5_figures.py       one script, three figures
data/
  hc_sec5_figs.csv         healthcare aggregated metrics (alpha=2, MAD, N=50 slice)
  md_sec5_figs.csv         knapsack aggregated metrics (alpha=2, K=2 slice)
figures/                   output (regenerated by the script)
```

The two CSVs are per-method, per-seed **summary metrics** (normalized regret,
MAD prediction-fairness violation, prediction MSE) — 5 seeds per cell. They hold
no individual-level records; the healthcare metrics are aggregates over the
patient cohort, not patient data.

## Run

```
pip install numpy pandas matplotlib      # python >= 3.9; STIX fonts ship with matplotlib
python plot_sec5_figures.py
```

Writes `figures/fig_sec53_{hero_crisis_repair,imbalance_bars,capacity_bars}.{pdf,png}`.

## What each figure is

| Figure | File | Data slice |
|--------|------|------------|
| 1 (hero) | `fig_sec53_hero_crisis_repair` | HC MLP-64 and MD MLP-64/imbalance 0.6; regret vs MAD, arrows PTO→FPTO and DFL→Regret-and-MAD |
| 2 (imbalance) | `fig_sec53_imbalance_bars` | MD MLP-64 across imbalance ∈ {0,.2,.4,.6,.8}; grouped bars, regret \| MAD |
| 3 (capacity) | `fig_sec53_capacity_bars` | HC across {Linear, MLP-16, MLP-64}; grouped bars, regret \| MAD |

Error bars are 95% t-confidence intervals (df = 4, 5 seeds). Four methods are
shown per group: PTO, FPTO, DFL, Regret-and-MAD (see the paper's method table).
The anchor cell appears twice in the source masters (two grid files, identical
rows); the script dedupes so the reported std is the honest 5-seed value.

## Method-name mapping (CSV key → paper name)

The CSV `method` column uses code keys; the paper uses display names. The four
methods plotted are the `(method, lambda)` pairs below (mapping lives in the
`SERIES` dict at the top of the script — edit there to add or relabel a method):

| paper name | CSV `method` | `lambda` | color |
|------------|--------------|----------|-------|
| PTO | `fpto` | 0.0 | blue `#0072B2` |
| FPTO | `fpto` | 1.0 | sky blue `#56B4E9` |
| DFL | `fdfl` | 0.0 | gray `#7F7F7F` |
| Regret-and-MAD | `fdfl` | 1.0 | vermillion `#D55E00` |

`fpto`@0 is PTO (predict-then-optimize, MSE only) and `fpto`@1 is FPTO (adds the
MAD term); likewise `fdfl`@0 is DFL (decision regret only) and `fdfl`@1 is
Regret-and-MAD (regret + MAD). The CSVs also carry the rest of the pool
(`saa`, `fdfl-0.1/0.5/scal`, `pcgrad`, `nashmtl`, `wdro`, `fplg`, `mgda`) so the
advisor can add series without re-exporting data.

## For the advisor: how to modify a figure

Everything is in one file, `plot_sec5_figures.py`:
- **colors / markers / which methods** → the `SERIES` dict and `BAR_SERIES` list.
- **axis labels, titles, panel layout** → the per-figure functions `hero()`,
  `imbalance_bars()`, `capacity_bars()`.
- **confidence interval** → `TCRIT` (t, df=4) and `mci()`.
- **which cells** → the `.cap == ...`, `.imbalance == ...`, `alpha` filters.

No paper install is needed; the two CSVs in `data/` are the only inputs.

## Data provenance

The two CSVs are column-and-row slices of the canonical result masters:
`results/healthcare/main_v5_multiinstance/grid/tables/master_tagged.csv` and
`results/md_knapsack/main_v6_rowsum/grid/tables/master_tagged.csv`. Kept columns:
`method, lambda, seed, cap, alpha, {fairness_type,n_train | imbalance,n_groups},
test_regret_normalized, test_fairness, test_pred_mse`.
